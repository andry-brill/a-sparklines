# Sparklines Site

Web Flutter project demonstrating examples of the sparklines library.

## Getting Started

This project uses the local `any_sparklines` package at the repository root as a dependency. The `site/` directory is excluded from publication to pub.dev by the root `.pubignore`.

## Running

From this directory, run:

```bash
flutter run -d chrome
```

Or build for web:

```bash
flutter build web
```
